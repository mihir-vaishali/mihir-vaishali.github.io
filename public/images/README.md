# Images

Drop the real photography here using these exact filenames. Anything missing
renders as a designed gold/wine placeholder instead of a broken image, so the
site stays presentable while assets are still being collected.

| File                   | Used by                        |
| ---------------------- | ------------------------------ |
| `logo1.png`            | Studio logo above the couple    |
| `couple-photo.jpg`     | Circular portrait in the gold frame |
| `ganesh_sthapana.png`  | Event 1 — Ganesh Sthapana       |
| `ring_ceremony.png`    | Event 2 — Ring Ceremony         |
| `mahendi.png`          | Event 3 — Mahendi (disabled)    |
| `haldi.png`            | Event 4 — Haldi (disabled)      |
| `sangit.png`           | Event 5 — Sangeet (disabled)    |
| `wedding1.png`         | Event 6 — Wedding Ceremony      |
| `reception.png`        | Event 7 — Reception (disabled)  |

Toggle an event on or off with its `enabled` flag in `src/config/site.js`.
